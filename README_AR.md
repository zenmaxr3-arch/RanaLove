# رنا ❤️ — تطبيق هدية عيد الميلاد

النسخة الأولى من مشروع Android.

## الموجود الآن
- واجهة رئيسية باسم رنا.
- تاريخ التعارف: 5/3/2026.
- أقسام: ذكرياتنا، صورنا، شعر لرنا، محادثتنا، أغانينا.
- الأغنية المسجلة في التصميم: بينا ميعاد.
- تاريخ عيد الميلاد سيبقى قابلًا للتعديل.

## المرحلة التالية
1. إضافة معرض الصور الحقيقي.
2. محرر الذكريات والقصائد.
3. مشغل الأغنية بعد توفير الملف الصوتي المرخص/المتاح للاستخدام.
4. شاشة مفاجأة عيد الميلاد.
5. تسجيل حسابين وربط المحادثة بقاعدة بيانات وخادم آمن.

> المراسلة الحقيقية بين جهازين تحتاج Backend ومصادقة؛ لا يتم وضع كلمات مرور أو مفاتيح خدمة داخل التطبيق.
